# Quilt Loader

### A fork of Fabric focused on features and compatibility

Quilt Loader is a Minecraft mod loader forked from Fabric, adding powerful new features including improved dependency resolution, built-in library mods, and better developer tooling while remaining Fabric-compatible.

<br>

---

## Features

| | |
|:---|:---|
| **Fabric Compatibility** | Run most Fabric mods without modification on Quilt |
| **Better Dependencies** | Improved dependency resolution prevents version conflicts |
| **Built-in Libraries** | Includes common library mods so they don't need separate installation |
| **Developer Friendly** | Improved debugging tools and APIs for mod authors |
